# 🧾 Billing System in C

A simple **Billing System** developed using the **C programming language**.
This project allows users to enter multiple items, their quantities, and prices, and then generates a simple bill with the total amount.

## 📌 About the Project

This is a beginner-friendly C programming project designed to practice fundamental programming concepts such as:

* Variables
* Arrays
* Strings
* Loops
* User input
* Arithmetic operations
* Formatted output

## ✨ Features

* 🛒 Enter multiple items
* 🔢 Enter item quantities
* 💰 Enter item prices
* 🧮 Automatically calculate the total for each item
* 📋 Display all items in a bill
* 💵 Calculate the grand total
* 🙏 Display a thank-you message

## 🛠️ Technologies Used

* **Language:** C
* **Compiler:** GCC / Turbo C++ compatible with minor syntax adjustments
* **IDE:** VS Code / Turbo C++

## ▶️ How to Run

### Using GCC / VS Code

1. Save the source code as:

```text
billing.c
```

2. Open the terminal in the project folder.

3. Compile the program:

```bash
gcc billing.c -o billing
```

4. Run the program:

```bash
./billing
```

### 🖥️ Windows

```bash
.\billing
```
